PostgreSQL Database Configuration

This plugin uses environment variables for configuration. Set the following environment variables before starting Jellyfin:

Required Environment Variables

  • POSTGRES_PASSWORD - Database password (required)

Optional Environment Variables (with defaults)

  • POSTGRES_HOST - Database host (default: localhost)
  • POSTGRES_PORT - Database port (default: 5432)
  • POSTGRES_DB - Database name (default: jellyfin)
  • POSTGRES_USER - Database user (default: jellyfin)

Query Cache and Optimisation (optional, experimental)

The plugin can cache home-screen queries (Latest, Resume) and run PostgreSQL-optimised Latest queries. These features are provided as-is; all failures fall back to the standard Jellyfin queries.

  • Pgsql_CACHE_ENABLED - Enable query result caching (default: true)
  • Pgsql_CACHE_BACKEND - Redis, Memory or Off (default: Redis; falls back to Memory when no Redis connection string is set)
  • REDIS_CONNECTION_STRING - StackExchange.Redis connection string, e.g. redis:6379
  • Pgsql_CACHE_LATEST_TTL - Latest cache TTL in seconds (default: 120)
  • Pgsql_CACHE_RESUME_TTL - Resume cache TTL in seconds, 0 disables (default: 30)
  • Pgsql_CACHE_NEXTUP_TTL - NextUp cache TTL in seconds, 0 disables (default: 45)
  • Pgsql_PG_OPTIMIZE_LATEST - Enable PostgreSQL-optimised Latest queries (default: true)
  • Pgsql_PG_OPTIMIZE_MOVIES_LATEST / Pgsql_PG_OPTIMIZE_TV_LATEST / Pgsql_PG_OPTIMIZE_MUSIC_LATEST - Per-type overrides (default: inherit master flag)
  • Pgsql_PG_OPTIMIZE_NEXTUP - Enable PostgreSQL-optimised NextUp batch queries (default: true)
  • Pgsql_COMMAND_TIMEOUT - Database command timeout in seconds (default: 90)

Note: cached Latest lists can lag behind library changes by up to the configured TTL.

User Taste Profiles (optional)

Scheduled aggregation of favorites/plays into per-user taste profiles, used to re-rank movie More Like This and home recommendations. A shadow ML model can train for offline metrics without affecting live rankings until neural serving is enabled.

  • Pgsql_TASTE_ENABLED - Build and apply linear taste profiles (default: true)
  • Pgsql_TASTE_SHADOW_TRAIN - Train shadow model during the rebuild task (default: true)
  • Pgsql_TASTE_NEURAL_SERVE - Use neural scores in live ranking (default: false)
  • Pgsql_TASTE_LOOKBACK_DAYS - History window in days (default: 730)
  • Pgsql_TASTE_MIN_SAMPLES - Minimum positive signals per user (default: 3)
  • Pgsql_TASTE_MAX_BONUS - Cap for linear taste bonus (default: 180)
