Seerr

Proxies media search and one-click requests to a Seerr instance. The API key stays on the Jellyfin server; requests are attributed to the Jellyfin user by matching username / jellyfinUsername in Seerr.

Base URL of your Seerr instance (no trailing slash required).
Seerr API key. The key user needs request rights and MANAGE_REQUESTS so Jellyfin can create requests on behalf of mapped users.
Maximum number of requestable titles to show in search (1–50).
